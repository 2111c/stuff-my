# stuff-my

## Run the game

# Run `python main.py` from the project directory. The main menu provides Story, Combatants, The Dungeon, and Others. The game saves Keys, unlocked combatants, chapter progress, portrait counters, and paused Story teams in `player_save.json`.

# The initial roster is limited to the unlocked combatants and LIMBursts; additional units can be unlocked through the two Combatants portraits. The Dungeon offers a 10-floor run, with three random floor choices at each step and an Adversity choice after every three floors. Completing all 10 floors grants 3,600 Keys; combat victories also grant their usual Keys.

# Others is where character planes can be spent to unlock combatants and LIMBursts.

# Shops offer a rotating selection of RealiGear, team healing/revivals for 200 cash, or an explicit Leave option. Purchased RealiGear is removed from future shop selections.

# The Class Portrait features all combatants in a randomly selected class. Duplicate Class Portrait pulls grant 1-5, 10-30, or 40-60 planes to that character for Tier 1, Tier 2, or Tier 3 combatants respectively. A Tier 3 pull has a 35% chance to unlock a random LIMBurst instead. Tier 2 combatants cost 150 planes; Tier 3 combatants and LIMBursts cost 400 planes.

# The Everchanging Portrait features the Combatants that drop in order. The Remembrance Portrait is always available and features special combatants. It has a 45% Tier 3 LIMBurst conversion chance, with equal odds between an unowned featured burst and another unowned LIMBurst. Its featured combatants and bursts are excluded from Everchanging and Class Portrait pulls.

## Battle rewards and retries

# Each battle victory grants 300 Keys. Completing the Dungeon grants an additional 3,600 Keys. After a loss, choose whether to retry; retries restore the team's HP to maximum, morale to 50, and clear battle statuses.
